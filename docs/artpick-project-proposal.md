# 미술관 작품 이상형 월드컵 및 AI 취향 기반 작품 추천 서비스

## 1. 프로젝트 개요

### 프로젝트 주제

시카고 미술관의 공개 작품 데이터를 활용하여 작품 이상형 월드컵을 제공하고, 사용자의 선택 기록을 기반으로 AI가 미술 취향을 설명하고 새로운 작품을 추천하는 서비스.

### 한 줄 소개

> **마음에 드는 그림을 고르면서 나의 미술 취향을 발견하고, 좋아할 만한 작품을 추천받는 서비스**

### 주요 사용자

- 미술을 잘 모르지만 그림을 구경하는 것을 좋아하는 사용자
- 자신의 미술 취향을 알고 싶은 사용자
- 게임 형식으로 새로운 작품을 접하고 싶은 사용자
- 마음에 드는 작품을 모아 개인 컬렉션을 만들고 싶은 사용자

## 2. 기획 배경

미술 작품을 감상하고 싶어도 작가나 작품 이름을 모르면 무엇부터 찾아봐야 할지 어려울 수 있다. 미술 사조나 전문 용어를 기준으로 작품을 검색하는 방식은 입문자에게 부담이 된다.

본 서비스는 전문 지식 없이 **두 작품 중 더 마음에 드는 작품을 선택하는 방식**으로 미술 감상을 시작하도록 한다.

**작품 선택 → 월드컵 결과 → 취향 설명 → 새로운 작품 추천 → 개인 컬렉션 저장** 과정을 하나의 서비스에서 제공한다.

## 3. 프로젝트 목표

1. 누구나 쉽게 참여할 수 있는 작품 이상형 월드컵을 제공한다.
2. 사용자가 선택한 작품과 대결 기록을 저장한다.
3. 선택한 작품의 공통 특징을 바탕으로 취향을 설명한다.
4. 사용자에게 아직 보지 않은 작품을 추천한다.
5. 마음에 드는 작품을 저장하고 다시 감상할 수 있도록 한다.

## 4. 핵심 서비스 흐름

```text
월드컵 시작
    ↓
라운드 선택
    ↓
두 작품 중 선호 작품 선택
    ↓
선택한 작품 다음 라운드 진출
    ↓
최종 우승 작품 결정
    ↓
AI 취향 분석
    ↓
새로운 작품 추천
    ↓
작품 상세 확인 및 컬렉션 저장
```

**사용자의 선택을 새로운 작품 탐색으로 이어주는 것**을 핵심으로 한다.

## 5. 주요 기능

### 5-1. 회원가입 / 로그인

사용자별 월드컵 결과와 컬렉션을 관리한다.

- 회원가입
- 로그인 / 로그아웃
- 사용자별 참여 기록
- 사용자별 저장 작품

비회원도 월드컵에 참여할 수 있도록 하고, 결과를 계정에 저장하는 기능은 로그인 사용자에게 제공할 수 있다.

### 5-2. 월드컵 시작 설정

사용자가 진행할 라운드를 선택한다.

```text
나의 미술 취향 찾기

[ 8강 ]
[ 16강 ]

[ 시작하기 ]
```

초기 버전은 전체 후보 작품에서 무작위로 선정한다. 주제별 월드컵은 추가 기능으로 고려한다.

### 5-3. 작품 이상형 월드컵

두 작품의 이미지를 나란히 표시하고 하나를 선택한다.

```text
16강 · 3번째 대결

┌────────────────┐   ┌────────────────┐
│                │   │                │
│   작품 A 이미지 │ VS│   작품 B 이미지 │
│                │   │                │
└────────────────┘   └────────────────┘

     [ 선택 ]              [ 선택 ]
```

주요 기능:

- 작품 무작위 배치
- 선택한 작품의 다음 라운드 진출
- 현재 라운드 및 진행 상황 표시
- 이미지 확대
- 최종 우승 작품 결정

빠르게 여러 번 클릭해도 하나의 대결에서 선택이 중복 반영되지 않도록 처리한다.

### 5-4. 월드컵 결과

우승 작품과 선택 기록을 보여준다.

```text
🏆 내가 선택한 작품

[ 우승 작품 이미지 ]

작품명
작가
제작 시기

[ 작품 자세히 보기 ]
[ AI 취향 분석 ]
[ 컬렉션에 저장 ]
[ 다시 하기 ]
```

### 5-5. 작품 상세

- 작품명
- 작가
- 제작 시기
- 재료 및 기법
- 작품 분류
- 제공되는 작품 설명
- 미술관 원문 링크

정보가 없는 항목은 생략하거나 ‘정보 없음’으로 표시한다.

## 6. 작품 데이터 연동

### 활용 API

**Art Institute of Chicago API**

작품 목록·상세·검색 데이터를 JSON으로 제공하며, 작품의 `image_id`를 이용해 별도의 IIIF 이미지 URL을 구성할 수 있다.

- [공식 API 문서](https://api.artic.edu/docs/)

### 활용 정보 예시

```text
작품 ID
작품명
작가명
제작 시기
이미지 ID
재료 및 기법
작품 분류
스타일 정보
작품 설명
공개 이미지 이용 여부
```

### 초기 데이터 범위

12일 프로젝트에서는 **이미지가 정상적으로 표시되고 공개 이용 조건이 확인되는 회화 작품 50~100개**를 먼저 선정한다.

작품 정보를 DB에 저장하여 월드컵마다 동일한 정보를 반복 조회하지 않도록 한다.

## 7. 사용자 선택 기록 관리

AI 분석에는 우승 작품뿐 아니라 대결별 선택 기록을 활용한다.

```text
1번째 대결
작품 A 선택 / 작품 B 미선택

2번째 대결
작품 C 선택 / 작품 D 미선택

결승
작품 A 선택 / 작품 C 미선택

최종 우승
작품 A
```

저장 정보:

- 참여 사용자
- 월드컵 진행 일시
- 라운드
- 대결에 등장한 작품
- 선택한 작품
- 최종 우승 작품

같은 작품이 여러 라운드에서 선택되었다는 점을 반영하여, 단순 승리 횟수만으로 취향을 단정하지 않는다.

## 8. AI 미술 취향 분석

선택 기록과 작품 정보를 AI에 전달하여 취향 설명을 생성한다.

### 예시 입력

```text
사용자가 선택한 작품과 미선택 작품의 정보입니다.

작품별 제공 정보
- 작품명
- 작가
- 제작 시기
- 작품 분류
- 스타일 정보
- 작품 설명

대결별 선택 기록을 참고하여
선호 작품의 공통 특징을 설명해주세요.

제공된 정보로 확인할 수 없는 특징은
확정적으로 표현하지 마세요.
```

### 예상 결과 예시

```text
🎨 이번 선택에서 발견한 취향

인물 중심의 작품보다 자연과 풍경을 다룬 작품을
여러 대결에서 선택했어요.

이번 월드컵에서는 일상적인 풍경을 표현한 작품에
더 관심을 보인 것으로 보여요.
```

분석 결과 구성:

- 짧은 취향 제목
- 선택 작품의 공통 특징
- 근거가 되는 작품
- 다음에 탐색할 만한 주제

색감·구도처럼 이미지 자체를 봐야 판단할 수 있는 특징은 **이미지 분석을 추가하는 경우**에 다룬다. 초기 버전은 작품 메타데이터와 설명을 기준으로 분석한다.

## 9. 취향 기반 작품 추천

선택한 작품과 유사한 특징을 가진 새로운 작품을 추천한다.

```text
사용자의 선택 기록
        ↓
선호 작품의 분류·스타일·설명 확인
        ↓
내부 작품 데이터에서 후보 선정
        ↓
이미 본 작품 제외
        ↓
AI가 후보별 추천 이유 작성
```

### 추천 결과 예시

```text
🖼️ 이런 작품도 살펴보세요

[ 추천 작품 이미지 ]

작품명 / 작가

추천 이유
이번 월드컵에서 선택한 작품들과
풍경을 다룬다는 공통점이 있어요.

[ 작품 상세 ]
[ 컬렉션에 저장 ]
```

추천 대상은 실제 확보한 작품 데이터 안에서 선정한다. AI에는 후보 목록을 전달하여 작품 ID와 추천 이유를 반환받는다.

초기 버전은 작품 분류·스타일 등 확인 가능한 항목을 비교하는 간단한 방식으로 구현한다.

## 10. 내 작품 컬렉션

사용자가 마음에 드는 작품을 저장한다.

```text
내 컬렉션

[ 작품 A ] [ 작품 B ] [ 작품 C ]

작품 A
메모: 방에 걸어두고 싶은 그림

작품 B
메모: 색이 인상적이었던 그림
```

주요 기능:

- 작품 저장
- 저장 작품 목록
- 감상 메모 작성 / 수정
- 컬렉션에서 제거
- 작품 상세 이동

작품 정보는 외부 데이터를 활용하고, 컬렉션과 메모는 사용자 데이터로 관리한다.

## 11. 결과 공유 기능

추가 기능으로 월드컵 결과를 공유할 수 있다.

```text
나의 미술 취향

🏆 우승 작품
[ 이미지 ]

AI 취향 소개
자연과 일상 풍경을 탐색하는 취향

[ 결과 링크 복사 ]
```

공유 페이지에는 사용자가 공개하기로 한 우승 작품과 분석 결과를 표시한다. 같은 후보 구성으로 친구가 월드컵을 진행하는 기능도 확장할 수 있다.

```text
공개 미술 작품 데이터

```

### 차별점

사용자가 전문 용어나 검색어를 입력하지 않아도 **작품을 고르는 행동만으로 취향을 탐색**할 수 있다.

월드컵 결과에서 우승 작품을 확인한 뒤 AI의 설명과 새로운 작품 추천으로 감상을 이어간다.
